## Afflictions and rising doom (reference)

Copied from the Claude Doc "Ostium: The Lore", section "Afflictions and rising doom", on 2026-11-23. The lore doc is the source of truth; this copy is for reference.

A hero who fails a resolve test inside a world gains that world's affliction instead of Dread. Each affliction is an unplayable curse card, like Dread, with an effect when drawn; the effects reuse statuses the combat code already has. Dread stays the affliction for practice rooms and the finale. The Infirmarium's "lift Dread" becomes "lift an affliction". Every effect value is a starting point for balancing.

Art rule (LORE_CHANGES item 4): the affliction cards read as wounds and fears, never as abstract penalties.
